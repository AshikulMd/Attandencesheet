# Student Attendance Management System (Attendancesheet)

A desktop application built with **JavaFX** designed for managing course attendance, calculating attendance statistics, and tracking student participation.

---

## Features

* **Multi-Course Management:** Create and switch between multiple courses and professors seamlessly[cite: 2].
* **Interactive Attendance Grid:**
  * **1-Click (Primary Click):** Mark present (`✓`)[cite: 2].
  * **Double Click:** Mark absent (`✗`)[cite: 2].
  * **Right-Click Context Menu:** Quick options for Present, Absent, or Clear[cite: 2].
* **Dynamic Table Control:** Add/remove custom weekly modules, adjust session hours, and bulk-add or delete student entries[cite: 2].
* **Real-time Attendance Analytics:**
  * Interactive stat cards displaying Class Attendance Rate (%), Total Present Sessions, and Total Absent Sessions[cite: 2].
  * Automatic percentage calculation per week and overall course progress[cite: 2].
* **Search & Filter Options:** Filter students by search term (Name or ID) or status (*100% Present*, *Has Absences*, *Low Attendance <75%*)[cite: 2].
* **Export Functionality:** Export attendance data directly to `.csv` format[cite: 2].
* **Dual Theme Support:** Built-in Light Mode and Dark Mode toggle[cite: 2].

---

## Tech Stack

* **Language:** Java[cite: 2]
* **UI Framework:** JavaFX (Controls, Layouts, Properties, Collections)[cite: 2]
* **File Format:** CSV Export support[cite: 2]
